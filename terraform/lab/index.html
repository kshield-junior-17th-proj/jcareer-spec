24개 생성 계획은 안전 검사를 통과했지만, 새 계정의 IAM 역할 생성 권한이 없어 적용이 중단됐습니다. 일부 생성된 16개 항목은 검토된 삭제 계획으로 정리했고 현재 Lab 리소스는 0개입니다.

계획 확인

HTTPS 비공개 원본과 Bedrock 브로커를 포함해 생성 24개, 변경 0개, 삭제 0개를 확인했습니다.

Bedrock 직접 확인

합성 문장 한 건의 모델 응답을 확인했습니다. 애플리케이션 전체 경로를 통과한 결과는 아닙니다.

적용 중단과 복구

IAM 역할 생성 권한 부족으로 멈춘 뒤, 부분 생성 항목만 지우는 저장 계획을 적용해 상태를 비웠습니다.

다음 확인

제한된 IAM 권한을 준비한 뒤 원격 여섯 서비스, HTTPS 인증 경계, Bedrock 전체 경로와 재부팅 복구를 다시 확인합니다.

환경 운영 기준

접속·데이터·AI 권한을
분리합니다

환경을 만들기 전에 사용 권한, 예상 비용과 유지 기간을 확인합니다. 실행 결과는 별도의 검증 기록으로 남겨 설계와 배포 상태를 구분해 관리합니다.

관리 접속

SSH·RDP 인바운드 대신 Session Manager를 사용합니다. 사용자별 권한과 접속 기록은 조직의 접근통제 절차에 따라 관리합니다.

검증 데이터

회원·기업 시나리오는 합성 데이터로 확인합니다. 고객 정보와 운영 비밀은 이 환경에 반입하지 않는 것이 기본 원칙입니다.

AI 권한

Amazon Bedrock 관련 권한은 기본값에서 잠겨 있습니다. 승인된 검증 항목과 기간이 정해진 경우에만 별도로 활성화합니다.

MLOps 연계

서비스 검증 자료를 비교 수치 파일로 변환한 뒤, 별도 Terraform 루트의 모델 검증 흐름으로 전달합니다.
